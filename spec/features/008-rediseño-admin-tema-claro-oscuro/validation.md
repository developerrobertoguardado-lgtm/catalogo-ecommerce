# Validation: Rediseño visual del administrador y tema claro/oscuro

## Criterios de aceptación a validar
Validar el rediseño visual de todas las páginas administrativas, la coherencia de componentes inspirados en Sash, la alternancia y persistencia de temas, la adaptación móvil, la ausencia de desbordamientos y la conservación de textos, rutas y operaciones.

## Plan de testing
- Tests de feature para comprobar que las páginas admin mantienen sus rutas y elementos funcionales.
- Tests frontend/MCP para alternar claro/oscuro, recargar y verificar `localStorage`.
- Validación MCP de productos, categorías, pedidos, configuración y login.
- Validación responsive en anchos desktop y móvil, incluyendo menú, tablas y modales.
- Suite completa de regresión para asegurar que CRUD, búsqueda, paginación y alertas continúan funcionando.
