# Validation: Rediseño visual de tablas CRUD con estilo Sash

## Criterios de aceptación a validar
Verificar el estilo compartido de tablas CRUD, encabezados, filas, badges, acciones, estados vacíos y paginación; conservar filtros, búsqueda, modales, botones, confirmaciones, textos, rutas y operaciones; y comprobar los temas claro/oscuro y el responsive móvil.

## Plan de testing
- Tests de feature para comprobar que las vistas conservan datos, filtros, paginación y acciones.
- Tests de regresión para productos, categorías y pedidos.
- Validación MCP de cada tabla en tema claro y oscuro.
- Validación MCP en viewport móvil para confirmar ausencia de overflow de página.
- Suite completa del proyecto para asegurar que no cambió ninguna operación.
