# Validation: Imágenes de categorías y filtro visual en catálogo

## Criterios de aceptación a validar
Validar imágenes opcionales de categorías, formatos, reemplazo, eliminación de base y almacenamiento, fallback genérico, selección sombreada con texto semibold, botón de eliminar filtros, estados sin categoría/productos, compatibilidad de rutas/consultas y responsive.

## Plan de testing
- Tests de request para formatos, tamaño y archivo opcional.
- Tests CRUD para persistencia, reemplazo y eliminación física.
- Tests de catálogo para filtro seleccionado, fallback, limpiar filtros y estados vacíos.
- Validación MCP de formularios, imágenes circulares, selección visual y móvil.
- Suite completa para confirmar que las operaciones existentes no cambian.
