# Validation: Botón de filtros como icono pequeño en la versión móvil

## Criterios de aceptación a validar
- Botón icono visible en móvil, oculto en desktop; botón texto visible en
  desktop, oculto en móvil. Icono abre el offcanvas correctamente.

## Plan de testing
- Validación MCP en 390px: verificar que el botón icono es visible, el de
  texto no, y que el offcanvas se abre.
- Validación MCP en 1280px: verificar que el sidebar de filtros se mantiene.
