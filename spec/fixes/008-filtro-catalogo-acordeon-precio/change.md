# Change: Corregir estilo y comportamiento del filtro de catálogo

## Reproducción
1. Abrir el catálogo.
2. Revisar los acordeones Categoría y Precio.
3. Abrir o cerrar uno de ellos.
4. Revisar bordes, fondo, encabezados y control visual de precio.

## Comportamiento esperado
El filtro debe tener bordes finos, fondo ligeramente opaco, encabezados neutros, acordeones independientes y una presentación visual de precio tipo barra progress.

## Comportamiento actual
Los bordes son gruesos, el fondo es blanco, el encabezado usa color predeterminado, Precio se cierra al interactuar con Categoría y no existe presentación visual tipo progress.
