# Change: Miniatura del producto en modal de compra

## Reproducción
1. Abrir el detalle de un producto.
2. Pulsar `Comprar por WhatsApp`.
3. Revisar el resumen del pedido en el modal.

## Comportamiento esperado
El resumen muestra la miniatura del producto para que el usuario pueda identificarlo antes de confirmar.

## Comportamiento actual
El modal no contiene ninguna imagen del producto; solo muestra el nombre, cantidad y total.
